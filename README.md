# CombinedAssault

## Features
- Ground vehicles, aircraft, ships and emplacements on WFLib ballistics
- Content packs: glTF models whose nodes carry the rig, colliders, hit modules and sockets ([docs](docs/README.md))
- Hard fork of YWZJ-Studio's Limitless Vehicle
